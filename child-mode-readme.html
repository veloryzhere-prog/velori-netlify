VELORI Child Mode

Child Mode is an optional text-language filter for a conversation, with a personal preference that synchronizes to your account. It encourages kinder language; it is not a parental-control system or a guarantee that a conversation is safe.

Enable or disable

Open Messages, select a conversation, tap the name at the top, then Settings. The highlighted Child Mode switch applies immediately. A blocked-language notice also links directly to settings and provides a clearly labeled Turn off Child Mode action. Only the user’s own local preference changes; the message draft remains editable.

What it does

• Checks typed and pasted text before a message is sent or edited. A matching message stays in the composer and is not submitted by this VELORI client.

• Hides matching received message text and inbox previews on this browser while enabled. Matching search results and shared-content text are also limited.

• Includes the requested Hindi/Hinglish terms, common variants and a small English profanity list. Handles case, full-width characters, zero-width characters, common leetspeak and some punctuation/space-separated variants. Whole-word matching avoids innocent substrings such as London and chutney.

• Nicknames saved while the mode is on are checked too.

Important limits

• The preference belongs to the signed-in account and conversation on this browser. It does not sync to other browsers or devices. Anyone who can use this account/browser can disable it. There is no parent PIN, guardian verification or age verification.

• This version filters the current client. A different client or API can bypass it. It cannot stop another participant from sending a message from their device; their matching text is hidden here after receipt.

• It does not inspect images, videos, voice notes, text inside media, documents or linked pages. Media links can still contain unsuitable material. Never describe it as making media safe.

• A word list cannot detect all bullying, grooming, threats, sexual content, disguised language or context, and may sometimes flag legitimate language. Human judgment and reporting are still necessary.

• It does not automatically report people, notify guardians or change account privacy. Use Block and Privacy settings for separate controls. Chat message reporting needs the pending server function; failed requests do not claim a report was submitted.

• Data saved on a shared browser can be accessible to other people using that account/device. Clear account access when sharing devices.

Other personal chat controls

Themes, nicknames and Delete for me are also local to this account/browser. Delete for everyone uses the existing server-authorized soft-delete path for the sender’s own messages and only animates success after acknowledgement. Others may already have seen, downloaded or captured a message.

Server extension

The proposed database extension is kept in docs/proposals/chat-account-sync.sql for review, outside automatic migrations. It requires explicit approval under AGENTS.md before applying. Account-wide synchronization and server-side protections need separate deployment and authorization/privacy testing; they are not implied by this client feature.

Account synchronization

The client now supports syncing personal chat preferences and hidden-message references to your account. Settings show the actual sync status and a Retry sync button. Cached settings work offline. Account synchronization and private reporting are enabled on the hosted VELORI database. Pending settings retry when connected; devices refresh settings when opening a conversation or returning to the window. This is still an optional client text filter, not server-enforced parental control.
